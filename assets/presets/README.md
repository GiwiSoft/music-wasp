# Bundled MilkDrop presets

These six `.milk` presets come from the [lactea](https://github.com/M0Rf30/lactea)
project (`examples/web/presets/`), authored by M0Rf30.

- Source: https://github.com/M0Rf30/lactea
- License: MIT OR Apache-2.0, the same dual licence as lactea
- Format: MilkDrop 2/3 `.milk`

MusicWasp renders them with the `lactea` crate. Extra presets can be dropped into
`<data directory>/presets` as `.milk` or `.milk2` files; they appear in
**Settings → Visualizer** and in shuffle mode.
