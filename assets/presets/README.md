# Bundled MilkDrop presets

MusicWasp bundles two preset sets. All files are MilkDrop 2 `.milk` presets and
are rendered by the [`lactea`](https://github.com/M0Rf30/lactea) engine.

## lactea originals (6)

Authored by M0Rf30 for the lactea project (`examples/web/presets/`).

- Source: https://github.com/M0Rf30/lactea
- License: MIT OR Apache-2.0, the same dual licence as lactea

## Ryan Geiss presets (20)

The original MilkDrop presets by Ryan Geiss, including collaborations with
Stahlregen and Zylot. Taken from the original MilkDrop release pack collected by
the projectM project.

- Source: https://github.com/projectM-visualizer/presets-milkdrop-original
- MilkDrop presets were generally released without an explicit licence and have
  been redistributed by projectM and other players for two decades. projectM
  documents the practical position as public domain and removes any preset on
  the author's request:
  https://github.com/projectM-visualizer/presets-cream-of-the-crop/blob/master/LICENSE.md
- The original author names remain in every file name.

Extra presets can be dropped into `<data directory>/presets` as `.milk` or
`.milk2` files; they appear in **Settings → Visualizer** and in shuffle mode.
